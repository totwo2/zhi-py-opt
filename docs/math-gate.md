# 数学闸门细节（Math Gate）

> 从 SKILL.md 移出。SKILL.md 是执行手册，只保留结论；推导与统计细节放这里。

## 等价性验证

- **证人构成**：随机采样 + 边界样本（空 / 单元素 / 极值 / 负值 / 重复 / 非 ASCII / 非法输入）。
  边界值分析的理由：多数 bug 在边界触发，纯随机证人覆盖不到。
- **异常语义等价**：两者抛出同类型异常即视为等价（如对非法输入都抛 `ValueError`），
  避免把合法重写误杀。
- **唯一数学完备域**：`sort-small-net` 用 `binary_seq` 证人做 2^n 穷举，
  等价于任意输入的正确性证明，故豁免统计显著性要求（性能门槛仅用于"别倒退太多"）。
- **反例返回**：`verify_equivalence` 返回 `(ok, counterexample)`，失败时给出首个反例样本
  （如 `[]`、`-1`），调用方可据此直接定位错在哪个输入。

**实证**：demo 场景 1 的 join 重写在 `[]` 上旧返回 `''`、新返回 `','`。
旧纯随机证人放行，边界证人正确拒绝。

## 性能验证

- **配对交替测量**：同一轮内 old / new 交替执行，抵消环境漂移。
- **加速比估计**：取配对结果的**中位数**（抗 GC / 调度异常值），不是均值。
- **显著性检验**：配对符号检验（sign test，纯 stdlib 二项分布）。
  H0 = 新旧无差异，`p = P(Bin(K, 0.5) ≥ wins)`；经验域要求 `p < SIGN_ALPHA(0.05)`。
- **双条件入库**：加速比过门槛 **且**（经验域）通过显著性检验。

**实证**：两个完全相同的函数，旧的点估计闸门在 5 次 trial 中有 1 次算出 1.095x 并入库（噪声假阳性）；
新闸门 9 轮配对 p = 0.25 正确拒绝。真实存在加速时 9/9 胜、p = 0.002 正确放行。

**字段语义**：入库记录中 `speedup` 字段 = 配对加速比中位数；
另有 `p_value` / `n_pairs` / `wins` 三个统计背书字段。旧记录无这些字段时，
`report` 会标注「无统计背书·旧闸门记录，待复核」。

## 规模维度（交叉点 n\*）

`crossing_analysis(fn_old, fn_new, kind, spec, sizes=..., threshold=..., sample_fn=...)`
跨规模配对测量，返回 `{"curve": [(n, speedup)...], "n_star": ...}`。
n\* = 加速比首次达到门槛的最小规模，回答"这个优化从多大输入才开始赢"。

**注意**：默认证人类型可能与目标函数形态不匹配（如 `str-join` 域证人是字符串列表，
而待测函数要整数列表）。跨规模分析用 `sample_fn` 传入真实形态的样本。

**结论**：join vs `+=` 的加速比随输入规模单调上升——小列表上可能不划算，大列表才明显。
具体数字随 CPython 版本与负载形态变化，要拿你这台机器上的值，跑 `python3 scripts/bench_real.py`（按域 + 真实语料实测）。

## 版本感知

3.11+ 自适应特化、3.12 优化 `str +=`、3.13/3.14 tier-2 JIT 会系统性吃掉传统优化技巧的收益。
入库记录带 `py_version`；`report` 对旧版本记录提示「加速比可能已失效」。
判定"优化已过时"时用当前版本重跑 `adopt` 复核，不要直接信旧记录。

## 作废机制

复核发现假阳性时调用 `selfopt.retract(name, reason, domain, recheck_speedup)`，
追加到 `data/retracted.jsonl`——**不删 `library.jsonl`**（审计保留历史）。
`report` 在认证列表标注已作废并单列作废清单。

历史已作废记录（原始备份 `/tmp/selfopt-data-backup-20260912/`）：
`get_greeting` 复核 0.896x（反向）、某 `get_os_name` 函数复核 0.509x（反向），
均为 `dict-dispatch` 域旧点估计闸门的噪声假阳性。
